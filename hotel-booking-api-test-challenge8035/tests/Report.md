## گذارهای State مورد انتظار
- اتاق 101: `available` → `reserved` (رزرو موفق) → `occupied` (پرداخت). رزرو موازی/تکراری در حالت غیرآزاد باید 409 بدهد؛ پرداخت مجدد و لغو پس از پرداخت نیز 409 هستند. وضعیت رزرو از `reserved` به `paid` می‌رود.
- اتاق 102: `available` → `reserved` → `available` (لغو موفق). booking لغوشده به `cancelled` تغییر می‌کند و پیوند اتاق به booking پاک می‌شود.
- منابع ناموجود (booking یا room) باید 404 بدهند. برای خطاهای قراردادی، پیام‌های مورد انتظار نیز بررسی شده‌اند.
