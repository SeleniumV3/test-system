در این مسأله، یک سیستم رزرو و مدیریت درخواست مرخصی با APIهای Stateful و یک رابط کاربری واقعی ارائه شده است. تستر باید با استفاده از Postman جریان یکپارچه درخواست تا تأیید/رد مرخصی را به‌صورت وابسته به State بررسی کند و سپس با ابزار E2E (Playwright) عملکرد UI متصل به همین API را در سناریوهای موفق، ناموفق و مرزی تست نماید. رفتار سیستم در مواجهه با ترتیب نامعتبر، داده‌های ناقص یا تغییر State و اثر آن در UI باید تحلیل و گزارش شود.

چالش‌های اصلی
 Integration Testing – ارزیابی ارتباط بین سرویس‌ها (data flow) – Postman 
 UI / E2E Testing – بررسی عملکرد رابط کاربری (Playwright)
